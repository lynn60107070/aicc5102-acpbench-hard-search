\section{Introduction}
\label{sec:intro}

Large language models (LLMs) are increasingly considered as components of planning systems, either
as policies that choose the next action or as parts of a planner. Both uses require reasoning about
actions and their effects. ACPBench-Hard~\citep{kokel2025acpbenchhard} tests this reasoning with
open-ended questions generated from formal planning domains, together with a validation algorithm
for each task, and reports that, with few exceptions, even large models score below 65\%. We focus
on its Next Action task: given a natural-language description of a state and a goal, generate an
action that moves the state one optimal step closer to the goal. Repeating this step yields an
optimal plan, so it is exactly what an LLM acting as a policy must do; yet Llama~3.1~8B answers
only 25\% of these questions correctly~\citep{kokel2025acpbenchhard}.

ACPBench-Hard evaluates direct generation only: the model answers in a single call. On other
reasoning and planning tasks, searching over intermediate states generated by the LLM has helped,
as in Tree of Thoughts~\citep{yao2023tot} and Reasoning via Planning~\citep{hao2023rap}. It is open
whether this transfers to open-ended planning questions when no verifier is available, so that the
model must predict and judge the intermediate states itself, and when the extra compute that search
uses is accounted for.

We therefore ask: \emph{does LLM-guided search over LLM-predicted intermediate states improve Next
Action accuracy on ACPBench-Hard over direct generation, under a matched compute budget?} We first
reproduce the paper's direct-generation baseline (Section~\ref{sec:reproduction}). We then add a
best-first search in which the LLM proposes candidate actions, predicts their effects, and scores the
predicted states (Section~\ref{sec:method}), and compare it with direct generation, structured
prompting and best-of-$N$ on the same questions, budgets and validator, together with ablations of
each search component (Sections~\ref{sec:setup} and~\ref{sec:results}).

Our contributions are:
\begin{itemize}
  \item A reproduction of four ACPBench-Hard results (Next Action and Progression, Llama~3.1 8B and
        70B), all within the 95\% interval of the reported values; an independent re-run on a second
        machine that gave identical answers on all 130 test questions; and a fix that lets the
        official validator run on Windows.
  \item An LLM-guided best-first search for open-ended Next Action that uses no planner, simulator,
        applicability checker or oracle, released with its code, tests and prompts.
