\section{Method: LLM-Guided Search}
\label{sec:method}

\paragraph{Task and baselines.}
Each Next Action question describes, in natural language, a planning domain, the current state $s$,
the goal, and the action schemas; the answer is a single ground action. Our baseline is
\emph{direct generation}: the reproduced official setup of Section~\ref{sec:reproduction}, a 2-shot
prompt answered greedily in one call. Two further controls separate the effect of search from
simpler sources of gain: \emph{structured prompting}, which asks the model to write out the state,
the goal, a candidate action and its progress before answering, and \emph{best-of-$N$}, which
samples $N$ answers at temperature $0.7$ and returns the majority action. Neither control, nor the
search below, ever consults the validator.

\paragraph{Best-first search over predicted states.}
Our extension searches a tree whose nodes are pairs of a \emph{predicted} state description and the
action path that leads to it from the root, the state given in the question. Expanding a node uses
the LLM in three roles (Algorithm~\ref{alg:search}). The \emph{proposer} lists $k$ candidate actions,
most promising first, sampled at temperature $0.7$ and parsed with the benchmark's own action
grammar. For each candidate, the \emph{predictor} either describes the complete resulting state or
answers \texttt{NOT APPLICABLE}; such candidates are pruned: never scored or expanded, and returned only if every candidate is pruned. The \emph{evaluator}
then reasons in at most three sentences about how close the predicted state is to the goal and ends
with a line \texttt{Score: $N$} on a 0--10 scale; prediction and evaluation are greedy. The search
always expands the highest-scored unexpanded node with depth below $d$, and stops when no such node
remains or as soon as the budget of $B$ LLM calls is used. The answer is the first action on the
path to the highest-scored node. Each expansion costs at most $1 + 2k$ calls, so with the frozen
setting $k{=}3$, $d{=}2$, $B{=}14$, the search expands the root and then only its most promising
child. Because every node below that child shares its first action, this second expansion cannot
change the answer: under the frozen budget the search in effect selects among the root candidates,
and deeper predictions can only matter with a larger budget, which lets the subtrees of other
candidates compete (we test this in the ablations).

\begin{algorithm}[t]
\caption{LLM-guided best-first search (frozen: $k{=}3$, $d{=}2$, $B{=}14$ calls)}
\label{alg:search}
\begin{algorithmic}[1]
\State $\mathit{root} \gets$ state described in the question; $N \gets \{\mathit{root}\}$
\While{some unexpanded node in $N$ has depth $< d$ \textbf{and} calls used $< B$}
  \State $n \gets$ highest-scored unexpanded node with depth $< d$
  \For{each action $a$ in \textsc{Propose}$(n, k)$} \Comment{1 call}
    \State $s' \gets$ \textsc{Predict}$(n, a)$ \Comment{1 call}
    \If{$s' =$ \texttt{NOT APPLICABLE}} \State \textbf{continue} \Comment{pruned, not scored}
    \EndIf
    \State $c \gets$ child of $n$ with state $s'$ and path $n.\mathit{path} + [a]$
    \State $c.\mathit{score} \gets$ \textsc{Score}$(c)$; \ add $c$ to $N$ \Comment{1 call}
  \EndFor
\EndWhile
\State \Return first action on the path to the highest-scored node in $N \setminus \{\mathit{root}\}$
\end{algorithmic}
\end{algorithm}

\paragraph{What the search may not use.}
Every state and every judgment in the search comes from the LLM: there is no planner, simulator,
applicability checker, PDDL description, or oracle, and the official validator is used only to score final answers (Section~\ref{sec:reproduction}).

\paragraph{Evaluator variants.}
To test which component matters, we compare the frozen evaluator with alternatives that keep the
rest of the search fixed. \emph{Steps} asks the LLM to estimate the number of actions $h$ still
needed and ranks nodes by $f = \mathit{depth} + h$, i.e.\ A$^*$~\citep{hart1968astar} with an LLM
heuristic. \emph{Vote} makes one comparative call per expansion, in which the LLM picks the child
that makes the most progress, following the Tree of Thoughts evaluator~\citep{yao2023tot}.
\emph{Random} assigns random scores, and \emph{fixed} trusts the proposer's order. We also disable
state prediction, letting the LLM score actions directly from the parent state, and disable
pruning.

\paragraph{Design selection.}
Apart from a 10-question smoke run of an early prototype, all design choices were made on the validation split (40 questions, disjoint from the 130 test questions) and frozen before the test runs. The 0--10 evaluator was, by one or two questions, the best-performing search
variant for Llama~3.1~8B on validation, so it is the method we report; the other evaluators appear
as ablations.
