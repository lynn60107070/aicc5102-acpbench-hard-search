\section{Experimental Setup}
\label{sec:setup}

To compare methods under similar inference budgets, we set the Best-of-N parameter to $N = 14$, producing 14 candidates per question. This approximately matches the search method's mean of 13.4 LLM calls per question for Llama 3.1 8B and 11.4 for Llama 3.1 70B. The Best-of-N 8B runs used an average of 14.0 calls and 22,959 tokens per question. We report both calls and token usage to make the computational cost of each method explicit.
