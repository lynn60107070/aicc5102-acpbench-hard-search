\section{Experimental Setup}
\label{sec:setup}

We evaluate on the 130 test questions and use the disjoint 40-question validation split only for
tuning. Llama~3.1~8B Instruct is the main model and Llama~3.1~70B a second comparison. We compare
direct generation, structured prompting, best-of-$N$ and LLM-guided search, plus search ablations.

\paragraph{Budget matching.}
In the main comparison, search has a budget of $B=14$ calls and best-of-$N$ uses $N=14$. Search
averages 13.4 calls on 8B, because some searches stop early; best-of-$N$, however, uses more tokens
(22,960 vs.\ 13,722 per question). We therefore repeat the comparison under a shared cap of 14,000
tokens per question, with $N=8$; the cap also stops some searches early (12.2 calls on average).

\paragraph{Metrics and statistics.}
We report accuracy, calls and tokens per question, and error types (format errors, inapplicable or unknown actions, and actions that do not move closer to the goal). For search we also measure whether a
correct candidate is proposed, an analysis metric that uses the answer key and is not available
at inference time. Sampled methods are run with seeds 1, 2 and 3 and reported as mean $\pm$
standard deviation; direct generation is greedy. Methods are compared per question with the exact
McNemar test~\citep{mcnemar1947}.
