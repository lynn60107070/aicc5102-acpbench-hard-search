\section{Limitations}
\label{sec:limitations}

Our reproduction has several limitations. We reproduced one benchmark task in full, together with the Progression task, but some closed-model results could not be reproduced because the original API versions had been retired. Exact numerical replication is also difficult across hardware and numerical precision settings. Some implementation details, including the chat template and precision used in the original experiments, were not reported. The 70B results were obtained through a provider whose numerical precision was not specified.

Our extensions are also limited in scope. We evaluate two model sizes on a single benchmark task with 130 test questions, so the results may not generalise to other tasks or models, and the relatively small test set limits statistical precision. Prompt choices were tuned using 40 validation questions, which may influence performance on this benchmark. Finally, financial constraints limited the inference budgets and the number of experiments we could run. These findings should therefore be interpreted as evidence about the tested setup rather than as a general conclusion about search methods for language models.
