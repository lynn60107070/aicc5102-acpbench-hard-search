# Presentation (Tue 24 Nov)

`index.html` is the full slide deck: one self-contained file, no install needed.

**Open it:** download or clone, then double-click `presentation/index.html` (Chrome or Edge).

| Key | Does |
|---|---|
| → / ← or Space | next / previous slide |
| N | speaker notes for the current slide |
| R | replay the slide's animation (e.g. the search diagram on slide 11) |
| F | fullscreen |
| E | edit text in the browser (saved only in your browser) |
